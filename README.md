# 内部培训平台 - 管理后台

公司内部员工培训学习平台的管理端，供管理员维护课程、题库、试卷、考试指派与考试记录。

### 技术栈

Vue3 + Vite + Vue-Router + Element-Plus + Pinia + Axios

### 本地运行

```bash
npm install --legacy-peer-deps
npm run dev
```

* 需要 Node 20+（Vite 8 要求）
* 开发服务器：http://localhost:9528
* 请求经 Vite 代理转发到网关 http://localhost:7700

完整的后端启动方式见后端仓库的 `LOCAL_RUN.md`。

### 主要模块

| 模块 | 说明 |
| --- | --- |
| 概况 | 平台数据总览 |
| 课程管理 | 分类、课程、章节、讲师 |
| 考试管理 | 题库、试卷与组卷规则、课程指派、考试记录 |
| 用户管理 | 员工账号 |
| 网站管理 | 站点信息、轮播、导航 |
| 系统管理 | 菜单、角色、权限、系统配置 |
